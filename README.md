# Simulador de Asignación de Memoria y Planificación de Procesos

## 📌 Descripción

Este proyecto consiste en el desarrollo de un simulador de **asignación de memoria y planificación de procesos**, orientado a representar y analizar conceptos fundamentales de los sistemas operativos.

## 📋 Tablero de Trello

[Tablero de Trello](https://trello.com/b/xiJPa65M/simulador-de-asignaci%C3%B3n-de-memoria-y-planificaci%C3%B3n-de-procesos)

## 🎯 Objetivos

- Simular la asignación y liberación de memoria.

- Representar el estado de los procesos.

- Implementar algoritmos de planificación de procesos.

- Visualizar el estado de la memoria y los procesos.

- Analizar el comportamiento de las diferentes estrategias.

## ⚙️ Funcionalidades

- Gestión de procesos.

- Asignación de memoria.

- Liberación de memoria.

- Simulación de planificación.

- Visualización del estado de los procesos.

- Visualización del estado de la memoria.

- Implementación de diferentes algoritmos de planificación y asignación.
